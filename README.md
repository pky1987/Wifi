# Wi-Fi Password Viewer

A utility to display saved Wi-Fi passwords on a local device. This tool allows users to view network credentials stored in the system’s configuration files or network manager. It is intended to help recover forgotten Wi-Fi passwords or audit saved network configurations.

## Features

- Lists all Wi-Fi networks (SSIDs) previously connected to.
- Displays the passwords of saved Wi-Fi networks.
- Option to export network data to a text or JSON format for backup.
- Clean, simple interface for ease of use.
- Works offline, no internet connection required.

## Ethical Notice

This tool is **only intended to be used on devices and networks that you own** or have explicit permission to access. Unauthorized access to other networks may violate privacy laws and regulations.

  
## Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/wifi-password-viewer.git
   cd wifi-password-viewer
   ```
Example Output:
```bash

Password: mypassword123

SSID: OfficeWiFi
```
